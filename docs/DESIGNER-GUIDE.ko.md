# 디자이너 검수 안내

StyleSeed는 코딩 에이전트가 화면을 만들 때 따르는 디자인 규칙 모음입니다. 규칙 몇 개는 문서와 코드가 서로 다른 말을 해요. 어느 쪽이 맞는지는 디자이너만 정할 수 있습니다.

## 부탁드리는 일

카드 묶음 하나를 봐 주세요. 한 묶음은 카드 10장 이하입니다. 20~30분이면 끝나요.

카드 한 장에는 열어 볼 화면 링크와 질문 하나가 있습니다. 답은 말로 하시면 돼요. "동의", "조건부 동의", "반대" 가운데 하나를 고르고 한두 문장을 붙여 주세요. 값을 고르는 카드도 있습니다. 모르겠으면 건너뛰세요.

JSON이나 코드는 쓰지 않으셔도 됩니다. 받아 적는 일은 디자이너님의 AI 에이전트가 해요.

## 준비물

- GitHub 계정
- AI 코딩 에이전트 하나. Claude Code, Codex, Cursor 어느 것이든 됩니다.

## 시작하는 법

1. GitHub에서 `bitjaru/styleseed` 저장소를 열고 오른쪽 위 **Fork**를 누릅니다. 내 계정에 복사본이 생겨요.
2. 에이전트에서 그 복사본을 엽니다.
3. 아래 문단을 그대로 붙여 넣습니다.

> `docs/designer-review-agent.md`를 끝까지 읽어 줘. 그다음 `research/reviews/batch-01.md`의 카드를 한 장씩 한국어로 물어봐 줘. 내 답은 내가 한 말 그대로 적어 줘. 네 의견은 말하지 마. 다 끝나면 적은 내용을 나한테 보여 줘. 내가 확인하면 내 계정으로 PR을 열어 줘.

## 진행 순서

1. 에이전트가 카드 1번을 보여 줍니다. 링크를 열어 화면을 봐 주세요.
2. 답을 말합니다. 예: "조건부 동의. 표 안에서는 32px도 괜찮다."
3. 다음 카드로 넘어갑니다. 중간에 멈춰도 돼요. 답한 카드까지만 기록됩니다.
4. 마지막에 에이전트가 적은 내용을 전부 보여 줍니다. 틀린 곳은 고쳐 달라고 하세요.
5. 확인이 끝나면 에이전트가 PR을 엽니다. 제출 전에 PR 본문을 한 번 읽어 주세요.

에이전트가 답을 유도하면 그 카드는 건너뛰어 주세요. 기록에는 디자이너님이 직접 내린 판정만 남습니다.

## 답이 쓰이는 곳

PR이 머지되면 메인테이너가 답을 해당 규칙에 옮겨 적습니다. 규칙에 검수자 이름, 날짜, 판정이 붙어요. 남기신 문장은 고치지 않고 그대로 옮깁니다.

반대와 조건부 답은 규칙을 고치는 근거가 됩니다. 입력창 높이를 40px로 답하시면 문서와 컴포넌트를 그 값에 맞춰요.

## 크레딧

- PR 작성자가 디자이너님 계정입니다. 머지되면 GitHub 기여자 목록에 올라가요.
- 규칙의 검수 기록에 이름이 남습니다. 실명과 핸들 가운데 원하는 쪽을 에이전트에게 말해 주세요.
- README 감사 목록에 올릴지는 PR 본문에서 고릅니다.

## 공개 문구의 한계

StyleSeed가 밖에 쓰는 문장은 한 가지입니다. "디자이너 1인 검수(AI 보조 기록), 카드 N장, 날짜." 이름은 동의하신 경우에만 붙여요. "전문가 승인", "디자이너 합의" 같은 표현은 쓰지 않습니다. 저장소 테스트가 그런 문구를 막아요.

디자이너님 이름이 들어가는 공개 문장은 올리기 전에 먼저 보여 드립니다. 마음에 들지 않으면 빼 달라고 하세요.

StyleSeed 설계에 함께 참여한 분의 검수에는 그 관계를 같이 적습니다. 독립된 제3자 평가로 읽히면 안 되거든요.

## 철회

답 하나, 이름, 검수 전체를 언제든 뺄 수 있습니다. 에이전트에게 삭제 PR을 열어 달라고 하세요. 메인테이너에게 말씀하셔도 됩니다. 공개 저장소라서 git 기록에는 이전 버전이 남아요.
