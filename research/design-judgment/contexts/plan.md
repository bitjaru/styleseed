# Condition D — short implementation plan

Before implementation, write a concise, reviewable plan covering information priority,
component/pattern selection, state transitions, responsive treatment, and explicit exceptions
or unsupported inputs. Name the files/APIs you intend to reuse. Do not provide private reasoning
or an extended chain of thought. Then implement the same task under the same budget as the other
conditions. Planning time/tokens are part of this condition's total cost, not free extra budget.
